# دليل المستخدم والإدارة

استخدم عنوان النسخة التي يديرها مسؤول المنصة. يبدأ تسجيل الدخول من `/login.html` عبر HTTPS. الواجهة عربية وتدعم عرض صندوق المحادثات في شاشة الهاتف ضمن عرض القائمة أو عرض المحادثة. صلاحيات العمليات تُطبّق على الخادم من الجلسة المرتبطة بالمؤسسة.

| الدور | البداية | المهام |
|---|---|---|
| مدير المنصة `SuperAdmin` | `/platform-admin.html` | المؤسسات ومديروها والباقات والاشتراكات وسجل العمليات. |
| مدير المؤسسة `Admin` | `/index.html` | الفريق والحسابات والقوالب والبوتات والحملات والتقارير والباقة، إضافة إلى مهام المحادثات. |
| الموظف `Agent` | `/index.html` | المحادثات والردود والعملاء ضمن مؤسسته، مع قراءة بعض البيانات التشغيلية. |

## مدير المنصة

1. افتح **الباقات** وأنشئ باقة باسم واضح. عيّن حدود الرسائل الشهرية والموظفين وحسابات واتساب والبوتات والمقالات، وحدّد إتاحة الحملات ومعاينة النموذج الخاص.
2. افتح **المؤسسات** وأنشئ المؤسسة ومديرها الأول. اختر الباقة وتاريخ انتهاء الاشتراك. تحفظ المنصة وقت الانتهاء بصيغة UTC بعد تحويله من وقت الجهاز.
3. لتجديد الاشتراك أو إيقافه اختر **الاشتراك** بجانب المؤسسة. لإيقاف المؤسسة أو إعادة تفعيلها استخدم زر الحالة.
4. عند فقد كلمة المرور اختر المؤسسة والمدير في نموذج إعادة الضبط. تُلغى جلسات المدير المرتبطة بالحساب بعد التغيير.
5. راجع **سجل العمليات** لمعرفة الإجراء والفاعل والتوقيت. تعرض الصفحة آخر 100 عملية.

الأسعار في الباقات للعرض الإداري. الاشتراكات تُدار يدويًا. إيقاف مؤسسة أو اشتراك يلغي الرسائل المجدولة والمعلقة المشمولة بالإيقاف. الرسالة التي بدأت عملية إرسالها قد تستمر؛ التفعيل لا يعيد الرسائل الملغاة إلى الطابور. حساب مدير المنصة يُجهّز في [إعدادات الخادم](operations.md#الحسابات-والصلاحيات).

## مدير المؤسسة

| الصفحة | الاستخدام |

| `/index.html` | عرض مؤشرات العملاء والمحادثات المفتوحة وغير المقروءة ورسائل اليوم بتوقيت UTC. |
| `/team.html` | إضافة الموظفين وتفعيلهم وإيقافهم وإعادة ضبط كلمات مرورهم وإلغاء جلساتهم. |
| `/whatsapp.html` | ربط أرقام واتساب والتحقق من الرموز المحفوظة وتحديثها وإعادة ربط الحسابات. |
| `/templates.html` | إدارة القوالب المرتبطة بحساب، وعرض القوالب واستخدام إرسال القالب وفق صلاحية Meta. |
| `/autoteplay.html` | إعداد قواعد الرد التلقائي القديمة. المسار `/autoreply.html` يحوّل إلى هذه الصفحة. |
| `/bots.html` | تحرير المسودة ومحاكاتها ونشر الإصدار وإيقافه ومراجعة سجل التنفيذ. |
| `/knowledge.html` | إعداد المقالات ونشرها والبحث المحلي، ومعاينة النموذج الخاص إذا ضُبط في الخادم. |
| `/marketing.html` | تسجيل الموافقات وقوائم المستلمين وجدولة الحملات وتتبعها وإلغاؤها. |
| `/reports.html` | مؤشرات حركة الرسائل وحالات الطابور وآخر حالة محفوظة واتجاهات الأتمتة. |
| `/subscription.html` | عرض سريان الباقة وحدود الاستهلاك والميزات وتاريخ الانتهاء. |

### ربط حساب واتساب

1. جهّز **Phone Number ID** و**WABA ID** ورمز الوصول من Meta.
2. افتح **حسابات واتساب** واملأ النموذج، ثم اختر **التحقق من بيانات Meta** و**حفظ وربط الحساب**. يتحقق الخادم من وجود الرقم في WABA ويتأكد من ملكية المؤسسة وسعتها.
3. لإصلاح حساب قديم، اختر **تحديث التوكن** وأكمل WABA عند غيابه. يتطلب الحساب الموقوف **إعادة ربط الحساب** صراحةً.
4. اضغط **التحقق لدى Meta** لفحص الرمز المخزّن على الخادم. نجاحه يعني أن الرمز يستطيع قراءة عضوية هذا الرقم لدى Meta. تأكد من استقبال الرسائل وإيصالاتها باختبار مستقل للـWebhook والإرسال بعد الإطلاق.

يحذف **إيقاف الحساب** الرموز المحفوظة ويحتفظ بملكية الرقم وسجل المحادثات.

### البوت والحملات

- أنشئ مسودة بوت، نفّذ المحاكاة، ثم انشر النسخة المحفوظة. يعمل إصدار منشور واحد لكل مؤسسة. الردود التقليدية تعمل عند غياب إصدار منشور. استخدم عقدة الانتظار لمتابعة إجابة لاحقة وعقدة التحويل لتسليم المحادثة إلى موظف.
- جهّز موافقة العميل لكل حساب واتساب، ثم قائمة عملاء وقالب تسويقي معتمد. يسمح الخادم بالجدولة عند تفعيل الحملات والسماح بها في الباقة. يعيد العامل التحقق من الموافقة والقالب عند الإرسال.
- البحث في المقالات يعمل داخل التطبيق. معاينة النموذج الخاص عملية يطلقها المدير يدويًا وتحتاج إعداد مشغّل المنصة.

## المحادثات والعملاء

1. افتح `/inbox.html`. ابحث باسم العميل أو رقمه، أو فلتر حسب حالة المحادثة أو الموظف أو التحويل للبشر.
2. افتح المحادثة واعرض الرسائل. يمكن تغيير الحالة والوسوم وتصفير العداد. إسناد المحادثة لموظف نشط متاح للمدير.
3. أرسل نصًا أو مرفقًا في نافذة الخدمة. استعمل قالبًا مناسبًا عند انتهاء النافذة. رفع المرفق يرتبط بالمحادثة؛ إرساله خطوة مستقلة.
4. اضغط **استلام بشري** عند الحاجة لإيقاف الرد الآلي المعلّق، ثم أعد المحادثة للبوت حين تصبح جاهزة.
5. في `/contacts.html` حدّث الاسم والبريد والمرحلة والملاحظات والوسوم. أرقام العملاء والملفات والمحادثات مقيدة بنطاق المؤسسة.

| ما يظهر في سجل الرسائل | المعنى |
|---|---|
| قيد الانتظار | الرسالة مسجلة للطابور بانتظار التنفيذ. |
| `Sent` | أعادت Meta قبول الطلب ومعرّف الرسالة. |
| `Delivered` | وصل إيصال تسليم موقّع. |
| `Read` | وصل إيصال قراءة موقّع. |
| `DeliveryUnknown` | تعذر تأكيد النتيجة؛ افحص سجل Meta قبل إعادة الإرسال يدويًا. |
| `Failed` أو `Cancelled` | تعذر الإرسال أو أُلغي وفق حالة الطابور وسببها. |

يشرح [مرجع التشغيل](operations.md) كيف يميّز المشغّل نسخة المصدر عن نسخة الموقع وما يلزم للتحقق الفعلي.
