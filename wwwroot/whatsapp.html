ربط حساب WhatsApp جديد

الربط عبر Meta (تجريبي، عند إتاحته)

ابدأ محاولة ربط آمنة، ثم افتح نافذة Meta الرسمية. لا تستخدم هذه الوظيفة قبل اعتماد إعدادات الربط التجاري.

💡 دليل الإدخال من ميتا:
اذهب إلى Meta for Developers > تطبيقك > WhatsApp > API Setup.
- Phone Number ID: معرف الرقم.
- WABA ID: معرف حساب الأعمال.
- Access Token: من Graph API Explorer (v26.0) أو System User.
يتم جلب المؤسسات من قاعدة بيانات المنصة. لا يتم إنشاؤها عشوائياً.
🔒 يُرسل عبر HTTPS فقط. لا يُحفظ في المتصفح. يُشفر في الخادم قبل الحفظ.
